# ZL定盘

ZL定盘是一个个人决策 Agent：它不迎合使用者的初始倾向，而是从长期收益、选择权、复利、注意力成本和最坏损失出发作出明确选择，并强制进行反证和改判检查。

## 安装

添加 GitHub 插件市场：

```text
codex plugin marketplace add zlll27291-ux/zl-dingpan-marketplace
```

安装插件：

```text
codex plugin add zl-dingpan@zl-dingpan-marketplace
```

也可以在 ChatGPT 桌面端的 Plugins Directory 中选择 **ZL定盘** 安装。

## 使用

在 Codex 中显式调用：

```text
$zl-dingpan 这个案子接不接？替我决定。
```

也可以直接说：

- “ZL定盘，替我决定。”
- “ZL定盘，比较这两个方案的长期总账。”
- “ZL定盘，攻击一下我现在的判断。”

## 决策输出

重大问题默认包含：明确结论、主要矛盾、长期总账、情绪降噪、反证攻击和改判条件。

ZL定盘提供决策支持，不代替医生、律师、会计师等专业人士对具体高风险事项的核验与意见。
